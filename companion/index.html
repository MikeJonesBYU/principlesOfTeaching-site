A real site, redesigned

This is a course companion. It takes one small site that was really designed, really built, and is really deployed — the Principles of Teaching site — and puts it through Project 1’s design cycle: a card sort, a wireframe, a tree test, a functional prototype, a five-user task test, and a final prototype. The live site plays the role the project assigns to “an existing version you’re unimpressed by” — and the final prototype will really replace it.

It is written as a designer’s notebook. Each build is tested by the next study; each study’s findings feed the next build. Every study page is a worked example of the study you will run; every prototype is a working artifact you can click through.

One thing you must know first

The site is real. The prototypes are real. The studies are not. Nobody ran these sessions. Every participant, quote, and number in this companion was invented for teaching — and this time the fiction runs forward: the invented findings drive the real redesign. That only works honestly under strict rules, which is why they are written down.

Invented material is always visibly marked — a banner on every page, and a FICTITIOUS DATA stamp on every invented table, chart, quote, and number.

The design cycle

Three studies and three prototypes, in one chain: each build is grounded in the study before it and tested by the study after it. The through-line: no skill has “one true place.” The data scheme — information blocks with attributes — stays decoupled from display, so each rung is a richer view of the same single source. Stations appear here as they are written and built.

The design cycle is generated from the companion registry.
